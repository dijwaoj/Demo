# 放置 RPG 冒险者养成游戏 - 设计文档

## 概述

一款卡牌风格的放置养成 RPG 网页游戏。玩家收集冒险者角色，挂机打怪获取装备，强化角色推进关卡。纯前端实现，无需服务器，可部署到 GitHub Pages 分享。

## 技术方案

- **框架：** Vue 3（CDN 引入，无需构建工具）
- **存储：** localStorage 持久化存档
- **部署：** 静态文件，GitHub Pages

## 页面结构

单页面应用，底部 Tab 切换四个模块：

| Tab | 功能 |
|-----|------|
| 冒险 | 选择关卡，挂机战斗，战斗日志，掉落展示 |
| 角色 | 已收集角色列表，装备/卸下，属性详情 |
| 背包 | 装备列表，强化，出售 |
| 商店 | 金币抽卡，购买装备 |

## 角色系统

### 职业（MVP 4 个）

| 职业 | 定位 | 特点 |
|------|------|------|
| 战士 | 坦克/近战 | 高生命，高防御 |
| 法师 | 输出/远程 | 高攻击，低防御 |
| 弓手 | 输出/远程 | 高暴击，中等属性 |
| 牧师 | 辅助/治疗 | 提供回复，属性均衡 |

### 角色属性

- 生命值 (HP)
- 攻击力 (ATK)
- 防御力 (DEF)
- 暴击率 (CRIT)
- 等级（通过战斗获取经验升级）

### 角色获取方式

- 挂机掉落碎片（集齐一定数量合成角色）
- 商店用金币抽卡
- 特定关卡首次通关解锁

## 装备系统

### 装备部位

- 武器（提升攻击）
- 防具（提升防御/生命）
- 饰品（提升暴击/特殊属性）

### 品质等级

| 颜色 | 品质 | 掉落概率 |
|------|------|----------|
| 白色 | 普通 | 高 |
| 绿色 | 优秀 | 中 |
| 蓝色 | 精良 | 低 |
| 紫色 | 史诗 | 很低 |
| 橙色 | 传说 | 极低 |

### 强化系统

- 消耗金币提升装备等级
- 每级提升固定属性百分比
- 最高等级随品质递增

## 战斗系统

### 核心机制

- 自动战斗，无需操作
- 战斗间隔由关卡难度决定
- 每场战斗自动选择已上阵角色
- 战斗胜利获得：经验、金币、装备/碎片掉落

### 关卡结构

- 线性关卡推进（1-1, 1-2, ... 2-1, ...）
- 每个章节 10 个小关
- MVP 先做 3 个章节（30 关）
- 通关解锁下一关，可重复挂机已通关卡

### 挂机机制

- 选择关卡后自动循环战斗
- 显示战斗日志（战斗结果、掉落物品）
- 离线时根据时间计算挂机收益（上限 8 小时）

## 经济系统

- **金币：** 主要货币，战斗掉落，出售装备获得
- **碎片：** 角色碎片，收集一定数量合成角色

## 存档系统

- localStorage 存储所有游戏数据
- 手动保存 + 自动保存（每 30 秒）
- 数据结构包含：角色列表、装备背包、关卡进度、金币数量、当前挂机状态

## UI 风格

- 卡牌风格，角色以卡片形式展示
- 品质边框颜色区分（白/绿/蓝/紫/橙）
- 简约图标（可用 emoji 或 CSS 图形）
- 响应式布局，支持手机浏览器
